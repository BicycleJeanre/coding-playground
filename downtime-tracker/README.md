# Downtime Tracker

A basic industrial plant downtime tracking app for multiple plants.

## Features

- Add and select multiple plants
- Track downtime events
- Track breakdown incidents
- Track critical spare parts
- Track observations

## Run locally

1. Install dependencies:

   ```bash
   cd downtime-tracker
   npm install
   ```

2. Start the app:

   ```bash
   npm start
   ```

3. Open http://localhost:3000 in your browser.
