# GarageBand for Mac Master Guide

**Last Updated: 2026-05-01**

This is the GarageBand-specific reference. It combines shortcuts, menus, setup, recording, mix workflow, and project organization into one place.

## What GarageBand Is Good At

- Sketching songs quickly
- Recording vocals and instruments
- Building around loops and drummer parts
- Doing simple arrangement and mixing work
- Keeping a project manageable without heavy routing complexity

If a session starts needing deeper routing, advanced buses, or more complex large-session management, Logic Pro is the better fit.

## What The Main Panels Do

### Library

Use it to choose and swap track patches.

### Smart Controls

Use it to adjust tone, effect intensity, and plugin or amp settings for the selected track.

### Audio Editor

Use it for audio timing edits, cleanup, and Flex-based work.

### Piano Roll Editor

Use it for MIDI note editing, quantizing, and note placement.

### Score Editor

Use it for notation and printed parts.

### Drummer Editor

Use it to adjust drummer patterns, feel, and complexity.

### Loop Browser

Use it to search and preview loops.

### Note Pad

Use it for track notes and reminders.

## Recording Setup

### Before Recording

- Set tempo
- Set key if needed
- Turn on metronome if you need a guide
- Decide whether count-in helps
- Arm only the track you need
- Check the input device and level

### During Recording

- Record a few takes if the part matters
- Leave room before and after the section
- Use headphones to avoid bleed

### After Recording

- Name the region
- Trim silence
- Split usable sections
- Keep the best take and mute the rest

## Mix Setup

### Start With Levels

Before effects, make sure:

- Kick and bass are balanced
- Lead elements are not buried
- Vocals sit above the music if the track has vocals
- Nothing is clipping the master output

### Order of Operations

1. Balance faders
2. Pan for space
3. Clean up noise or bad edits
4. Add EQ if parts conflict
5. Add compression if a sound needs control
6. Add reverb or delay for depth
7. Automate changes over time

### Common Problems

#### Vocal Is Too Quiet

Try:

- Raising the vocal fader
- Cutting competing instruments in the same range
- Adding a little compression
- Reducing reverb if the voice feels too far away

#### Bass Is Muddy

Try:

- Lowering overlapping low-end parts
- Simplifying the bass pattern
- Reducing other low-frequency layers
- Checking whether the kick and bass are stepping on each other

#### Mix Feels Small

Try:

- Adding panned supporting parts
- Using a wider stereo element
- Layering a quieter texture under the main part
- Increasing contrast between sections

#### Mix Feels Harsh

Try:

- Reducing bright layers
- Pulling back treble-heavy loops
- Taming the lead sound
- Checking headphone volume before changing EQ

## Project Organization

### Naming

Use names that say what the track does.

Good examples:

- `VOX - Lead`
- `VOX - Doubles`
- `DRUM - Kick`
- `DRUM - Snare`
- `BASS - Sub`
- `BASS - Mid`
- `FX - Risers`
- `REF - Original`

### Section Marking

Use arrangement markers or rough section labels:

- Intro
- Verse
- Chorus
- Breakdown
- Build
- Drop
- Outro

### Versioning

Use versions when the change matters:

```text
track-name_v01.band
track-name_v02.band
track-name_mix-v03.band
track-name_final-v04.band
```

### Keeping Sessions Clean

- Keep raw material in a reference track
- Mute unused takes
- Delete experiments once they are no longer useful
- Lock finished parts if needed
- Keep a rough mix bounce for comparison

### Folder Habit

```text
Project Name/
  GarageBand/
  Audio/
  Exports/
  References/
  Notes/
```

## Practical Workflow

### Record a Part

```text
Choose track -> Arm track -> Check input -> Set level -> Record -> Trim -> Rename region
```

### Edit a Long Region

```text
Zoom -> Split -> Loop a section -> Clean timing -> Rename sections -> Join only when final
```

### Build a Session

```text
Add drums -> Add bass -> Add hook -> Add support layers -> Add FX -> Mark arrangement -> Mix
```
