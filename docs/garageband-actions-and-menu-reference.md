# GarageBand Actions and Menu Reference

**Last Updated: 2026-05-01**

This reference is a map of what GarageBand can do on Mac. It is organized around the main menus, windows, and track actions so you can quickly find where a task lives and what keyboard shortcut goes with it.

Some commands only appear when the right track, editor, or browser is active. If a shortcut does not work, check the menu bar for the current context.

## Core Navigation

| Action | What it does | Shortcut |
|---|---|---|
| New project | Starts a new GarageBand project | `Command-N` |
| Open project | Opens an existing project | `Command-O` |
| Save project | Saves the current project | `Command-S` |
| Save As | Saves a new copy of the current project | `Shift-Command-S` |
| Close project | Closes the current project window | `Command-W` |
| Quit GarageBand | Exits the app | `Command-Q` |
| Play / stop | Starts or stops playback | `Space` |
| Record | Arms recording from the current position | `R` |
| Go to beginning | Moves the playhead to the start | `Return` |
| Go to end of last region | Jumps to the end of the last region | `Option-Return` |
| Move playhead left | Steps the playhead left | `,` |
| Move playhead right | Steps the playhead right | `.` |
| Toggle cycle | Turns cycle mode on or off | `C` |
| Toggle metronome | Turns the metronome on or off | `K` |
| Toggle count-in | Turns count-in on or off | `Shift-K` |

## File Menu Actions

| Action | What it does | Shortcut |

## Track Header Controls

These are not always menu items, but they are central to using GarageBand well.

| Control | What it does |
|---|---|
| Mute | Silences the track |
| Solo | Hears only the selected track or tracks |
| Volume | Adjusts track level |
| Pan | Moves sound left or right in the stereo field |
| Record enable | Prepares a track for recording |
| Input monitoring | Lets you hear the live input signal |
| Lock | Prevents accidental edits and reduces clutter |

## Library

The Library is where you choose and swap track patches.

Useful for:

- Picking an instrument sound quickly
- Browsing presets
- Changing the tone of a track without rebuilding it
- Stepping through preset variations with `[` and `]`

## Smart Controls

Smart Controls are the quick-edit surface for the selected track.

Useful for:

- Adjusting tone
- Changing effect intensity
- Tuning the character of a patch
- Opening deeper plugin and amp settings

## Editors

### Audio Editor

Use it for:

- Audio timing edits
- Flex editing
- Basic cleanup of recorded audio

### Piano Roll Editor

Use it for:

- MIDI note editing
- Quantizing notes
- Changing note length and placement

### Score Editor

Use it for:

- Music notation
- Seeing MIDI in written form
- Printing parts or scores

### Drummer Editor

Use it for:

- Adjusting drummer performance patterns
- Changing energy and complexity
- Following another track’s rhythm

## Common Workflow Maps

### Record a Part

```text
Choose track -> Arm track -> Check input -> Set level -> Record -> Trim -> Rename region
```

### Edit a Long Region

```text
Zoom -> Split -> Loop a section -> Clean timing -> Rename sections -> Join only when final
```

### Build a Session

```text
Add drums -> Add bass -> Add hook -> Add support layers -> Add FX -> Mark arrangement -> Mix
```

## Best Mental Model

GarageBand has three layers of control:

1. The **menu bar** for project and editing commands.
2. The **window panels** for sounds, controls, and editors.
3. The **track headers** for playback, level, and recording control.

If you know which layer you need, the app becomes much easier to navigate.
