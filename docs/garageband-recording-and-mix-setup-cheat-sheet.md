# GarageBand Recording and Mix Setup Cheat Sheet

**Last Updated: 2026-05-01**

This cheat sheet covers the setup stage before you record or mix anything in GarageBand. Most beginner problems come from signal flow, bad levels, monitoring confusion, or starting to mix before the tracks are actually ready.

## What You Need First

- A project name
- The right track type
- A microphone, instrument input, or software instrument
- Headphones or monitors
- A clean recording environment
- A rough idea of the song structure

## Track Types

### Audio Track

Use for:

- Vocals
- Guitar
- Bass guitar
- External instruments
- Imported audio

### Software Instrument Track

Use for:

- MIDI keyboard parts
- Drum programming
- Synth lines
- Piano parts

### Drummer Track

Use for:

- Starting a rhythm section quickly
- Building a drum feel before programming your own parts

### Loop-Based Layer

Use for:

- Temporary arrangement ideas
- Background percussion
- Texture and filler parts

## Input Setup

### Basic Checklist

1. Pick the correct input device.
2. Confirm the correct input channel.
3. Set the recording level before you record.
4. Put on headphones to avoid bleed.
5. Monitor only what you need.

### Gain Rule

Record safely. If the signal clips, the take is usually harder to fix than a quieter take.

Target behavior:

- Loud enough to avoid noise
- Quiet enough to leave headroom
- Consistent enough to edit later

### Monitoring Rule

Monitor through headphones when recording microphones or instruments.

If you hear latency or delay:

- Reduce the monitoring chain if possible
- Close unnecessary apps
- Use simpler sessions when recording

## Recording Workflow

### Before Recording

- Set tempo
- Set key if needed
- Turn on metronome if you need a guide
- Decide whether count-in helps
- Arm only the track you need

### During Recording

- Record a few takes if the part matters
- Leave a little room before and after the section
- Keep speaking, playing, or singing with consistent energy

### After Recording

- Name the region
- Trim obvious silence
- Split out usable sections
- Keep the best take and mute the rest

## Mix Setup

### Start With Levels, Not Effects

Before adding effects, make sure:

- Kick and bass are balanced
- Lead elements are not buried
- Vocals sit above the music if the track has vocals
- Nothing is clipping the master output

### Order of Operations

1. Balance faders
2. Pan for space
3. Clean up noise or bad edits
4. Add EQ if a part conflicts with another part
5. Add compression if a sound needs control
6. Add reverb or delay for depth
7. Automate changes over time

### Practical Level References

- Kick and snare should be obvious in the groove
- Bass should support the kick, not fight it
- Leads should stand out without making the mix harsh
- Pads should fill space without taking focus

## Common Mix Problems

### Problem: Vocal Is Too Quiet

Try:

- Raising the vocal fader
- Cutting competing instruments in the same range
- Adding a little compression
- Reducing reverb if the voice feels too far away

### Problem: Bass Is Muddy

Try:

- Lowering overlapping low-end parts
- Simplifying the bass pattern
- Reducing other low-frequency layers
- Checking whether the kick and bass are stepping on each other

### Problem: Mix Feels Small

Try:

- Adding panned supporting parts
- Using a wider stereo element
- Layering a quieter texture under the main part
- Increasing contrast between sections

### Problem: Mix Feels Harsh

Try:

- Reducing bright layers
- Pulling back treble-heavy loops
- Taming the lead sound
- Checking headphone volume before making EQ decisions

## Effects Use

### Use Reverb For

- Space
- Depth
- Smooth transitions

### Use Delay For

- Movement
- Rhythmic repeat
- Vocal throw effects

### Use Compression For

- Controlling loud peaks
- Tightening vocals
- Making parts feel more even

### Use EQ For

- Removing mud
- Creating separation
- Making room for the important part

## Recording And Mix Cheat Rules

- Set the input correctly before you record.
- Leave headroom.
- Monitor in headphones.
- Fix the arrangement before overprocessing the mix.
- Start with volume balance.
- Use effects to support the sound, not rescue a broken recording.
- Keep the low end simple.

## Good Session Habits

- Save versions before major changes.
- Name regions as soon as they become useful.
- Mute unused takes.
- Keep one raw copy if you might need to redo edits.
- Bounce a rough mix when you need a reference outside the session.
